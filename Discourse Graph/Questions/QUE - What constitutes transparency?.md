## Context
Claude:
> Raised by S13 (👩🏽‍🔬 Distiller, SP-24) in the session on [[@liptonMythosModelInterpretability2017]]. Aspects of an algorithm's behavior one might want to understand: does it converge, is there a unique solution, can we understand each parameter? Levels of transparency:
> - (macro) model = simulability: "a person can contemplate the entire model at once"; "can be readily presented to the user with visual or textual artifacts".
> - (micro) parameters = decomposability, aka intelligibility: "each node in a decision tree might correspond to a plain text description".
> - (event/process) algorithm = algorithmic transparency: seemingly what many scholars study, e.g., Distill.pub's [The Building Blocks of Interpretability](https://distill.pub/2018/building-blocks/).
