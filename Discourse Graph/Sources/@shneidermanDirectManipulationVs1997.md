## Discussion notes
Claude:
> Shared by Joel Chan as an announcement in the SP-25 seminar, as potentially relevant to the discussion of [[PTN - Direct Manipulation]] tradeoffs for novices: a 1990s debate between Ben Shneiderman and Pattie Maes on direct manipulation vs. interface agents (h/t [this tweet](https://twitter.com/mathisonian/status/1783897803556606291)).
> - Key quote from Maes's closing: there are "real limits to what we can do with visualization and direct manipulation because our computer environments are becoming more and more complex. We cannot just add more and more sliders and buttons", and users are not computer-trained, so some tasks will be delegated to agents. But this is "completely a complementary technique to well-designed interfaces—visualization, and direct manipulation—not a replacement. Users still need to be able to bypass the agent", and agent design must attend to "understanding and control... The user has to be able to understand what the agent does."
