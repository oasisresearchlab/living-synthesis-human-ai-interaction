## Description
Claude:
> A cognitive theory of decisions from experience, used in [[@guptaFosteringCollectiveIntelligence]] to build AI agents that collaborate with humans. It offers a single general algorithm and mathematical formulation of memory retrieval, built on existing cognitive architectures. Decisions are represented as instances (state, action, utility). The value of each option is accumulated by "blending", a function of payoffs experienced and the probability of retrieving those instances from memory (S11, Distiller, SP-24 W11).
> S11's take: "To me, this is the formulation of a classic reinforcement learning agent."
