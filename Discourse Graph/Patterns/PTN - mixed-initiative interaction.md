## Description/Intuition and Key Sources
> [!info] What is the key intuition for the pattern? Include links to key/canonical sources.
Claude:
> Interfaces that partner "automated services with direct manipulation", so that user and system each take initiative when appropriate. Canonical source: Horvitz, E. (1999). Principles of mixed-initiative user interfaces. CHI '99, 159–166. https://dl.acm.org/doi/pdf/10.1145/302979.303030 (no source note in the vault).
> - S08 (🏺 Archaeologist, SP-24 W04) traced it as the "older influence" on [[@heerAgencyAutomationDesigning2019]]: Microsoft Research, late 1990s, which became foundational principles. Heer discusses 4 of the 12 principles. Others include:
>   - "Employing dialogue to resolve key uncertainties"
>   - "Employing socially appropriate behaviors for agent-user interaction"
>   - "Maintaining working memory of recent interactions"
> - S16 (🤔 ELI5 linter, SP-24 W04) placed Horvitz as the synthesis position in the 1990s debate between direct manipulation and interface agents. See [[PTN - interface agents]] and [[PTN - Direct Manipulation]].
