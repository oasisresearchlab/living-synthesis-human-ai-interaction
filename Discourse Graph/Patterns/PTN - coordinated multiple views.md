## Description/Intuition and Key Sources
> [!info] What is the key intuition for the pattern? Include links to key/canonical sources.

Claude:
> Show the same items in several linked views, each organized by a different dimension, so users can see where one item sits across all of them. A standard information-visualization technique.
> In [[ART - Patchview]], users link views by creating an anchor and connecting views, "so that now it will try to coordinate across these ... views" (Joel Chan, SP-25 W11, [00:33:50]–[00:34:00]). A character can then be seen as "in the middle of law and chaos and ... closer to good than evil", combined into a 2D plane, radar charts, or parallel coordinates (SP-25 W11, [00:32:49]–[00:33:50]).
