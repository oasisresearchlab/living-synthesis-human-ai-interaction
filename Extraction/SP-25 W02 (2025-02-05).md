Claude:
> Reading: Wang et al. (2022), "Interpretability, Then What? Editing Machine Learning Models to Reflect Human Knowledge and Values" ([[@wangInterpretabilityThenWhat2022]]), which presents [[ART - GAM Changer]]. The discussion covered how the tool works (GAMs as glass-box models, shape functions as a shared representation, constrained direct manipulation, continuous feedback, reversible commented edits). It then turned to the bounds of the approach: GAMs only, high-dimensional models, and expert bias or overconfidence. The contested threads were whether to trust learned data patterns or expert judgment, where responsibility for edits lies, and how much the usability survey shows. Joel Chan discounted the Likert ratings and valued the semi-structured interviews.

### Questions

### Claims
- [[CLM - claims about a human-AI interaction design should be scoped to the model class it was built and tested with, not to AI in general]]
- [[CLM - glass-box models like GAMs trade some predictive power for the ability to reason about and edit each feature on its own]]
- [[CLM - interactive model editing tools should be evaluated against the counterfactuals of not editing the model and of engineers editing it in code through back-and-forth with domain experts]]
- [[CLM - interactive model editing tools do not correct for editors' own biases, so safeguards against biased edits must come from social and process mechanisms]]
- [[CLM - interpretable but non-explanatory model editing tools put the onus for correct edits on the user's expertise]]
- [[CLM - tools that surface discrepancies between model behavior and domain knowledge are preferable to tools that seem objective but hide those discrepancies]]
- [[CLM - direct manipulation interfaces for computational work should let users with more expertise drop down to fine-grained programmatic control]]
- [[CLM - self-reported usability ratings from short, uncontrolled sessions with the researcher present carry little evidential weight about a tool's usefulness]]
- [[CLM - model editing tools can let a dissenting expert show the consequences of a feature's learned behavior rather than only argue verbally]]
- [[CLM - being able to run a research system yourself raises confidence in its claims more than a recorded demo does]]
- [[CLM - aggregate findings about human-AI complementarity likely hide large heterogeneity driven by model type and interface details]]
- [[CLM - noticing a discrepancy between a model and expert knowledge is a separate problem from deciding whether to retrain, collect more data, or edit the model]]
